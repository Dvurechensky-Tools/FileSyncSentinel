## 27.08.2026

### Добавлено

- Добавлено обнаружение удалённых файлов: если файл исчез из `Out`, но остался в `In`, он попадает в список как удаление.
- Добавлены типы изменений и цветовая маркировка строк: добавление, изменение и удаление.
- Добавлены поиск по файлам и исключения по подпапке или пути.
- Добавлено массовое применение видимых изменений с учётом текущего поиска и исключений.

### Изменено

- Одиночное и массовое применение теперь используют типизированные действия, включая удаление файлов из `In`.
- Главное окно теперь можно изменять по размеру, а стартовая ширина увеличена для читаемости кнопок.
- В таблице изменений сокращены подписи действий и расширены колонки кнопок.
- Панель сравнения теперь растягивает обе текстовые области при изменении размера окна.

## 21.08.2026 - ver 1.1

### Добавлено

- Добавил обнаружение новых файлов в папке `Out`, включая вложенные директории.
- Добавил отображение новых файлов в списке изменений.
- Добавил действие **Добавить** для новых файлов в таблице изменений.
- Добавил автоматическое создание недостающих подпапок в `In` при добавлении нового файла.
- Добавил обработку событий создания и переименования файлов в `FileSystemWatcher`.
- Добавил regression runner `FileSyncSentinel.Tests` для проверки обнаружения и копирования новых файлов.

### Изменено

- Массовое применение изменений теперь использует маску файлов из конфигурации, а не жестко заданное `*.ini`.
- Массовое применение теперь копирует новые файлы из `Out` в `In`, а не пропускает их.
- Просмотр различий теперь корректно открывается, даже если эталонный файл еще отсутствует.
- README на русском переписан от первого лица в более профессиональном стиле с меньшим количеством emoji.
- README на английском переписан от первого лица в более профессиональном стиле с меньшим количеством emoji.
